# Tellme

**The web, spoken.**

Tellme is an AI-powered browser experience that turns long webpages and discussion threads into natural audio you can listen to while you work.

## Landing page

Built with Next.js, TypeScript, Tailwind CSS, shadcn/ui patterns, Framer Motion and Lucide icons.

## Roadmap

1. Landing page
2. Chrome extension shell
3. Reddit content extraction
4. AI thread understanding
5. Natural TTS playback
6. Background listening and controls
7. Quora and generic webpage adapters
8. Ask Tellme conversational mode

## Local development

npm install
npm run dev

Open http://localhost:3000.
