# Tellme Privacy Policy

Last updated: September 30, 2026

Tellme is a browser extension that reads webpage content aloud and can create a short, locally generated brief.

## Information Tellme accesses

When you choose **Listen to post** or **Give me a brief**, Tellme can access the active webpage's:
- page title and URL;
- visible page/article text;
- Reddit post, comments, and replies when the active page is a Reddit discussion;
- selected text when you explicitly use the selection reading command.

The floating Tellme interface is injected into supported web pages, but it does not inspect page content until you start a reading or brief action.

## How information is used

The accessed webpage content is used only to:
- extract the useful text for narration;
- generate the on-device quick brief;
- keep playback state so narration can continue while you change tabs.

Reader state and captured source information are stored in Chrome's local extension storage.

Tellme does not sell, rent, or use webpage content for advertising or behavioral profiling.

## Data transmission

Tellme's current extension implementation does not send webpage content to a remote analytics service or third-party advertising service. Speech playback uses the browser's speech capabilities.

## Data retention and deletion

Stored reader state and captured source data remain in the extension's local Chrome storage until the extension or its stored data is cleared. Uninstalling the extension removes its local extension storage.

## Changes

This policy may be updated when Tellme's data practices or functionality change. The latest version will be published in this repository.
